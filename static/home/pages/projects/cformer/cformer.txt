{c#ffff00}DESCRIPTION{c#ffff00}
        CFormer is most likely my most complex and impressive project to date.  A culmination in about a year and half of active development, CFormer is an implementation of a number of machine learning concepts, all implemented from scratch.

{c#ffff00}INSPIRATION{c#ffff00}
        The project originally began in the summer of 2024.  I was taking a machine learning class in the fall and wanted to touch up on my machine learning understandings.  At the same time, I wanted to relearn C++.  As a result, I sat down with my machine learning textbook and just started implementing a neural network, figuring out both the language and math as I went.

{c#ffff00}DEVELOPMENT{c#ffff00}
        The project was originally intended to just implement Dense neural networks, the most basic building blocks of modern AI.  However, as my machine learning class continued, I was inspired to go further and made it my final project to implement a full Multi-Head Attention Transformer.  By December, I had finished the implementation and used it train a sentiment detection model that was around 80% accurate.  Not bad for 6 million parameters and no GPU utilization!
        Later in the year, I started researching how to utilize the GPU in training.  Unfortunately, my work with the CUDA library never reached the main branch.  However, the information learned about GPU works and how to utilize them was invaluable.

{c#ffff00}DESIGN{c#ffff00}
        The project has gone through a number of redesigns.  Today, each neural network is treated as a doubly linked-list that forward and backward propagates to its neighbors.  Originally, the complex gradient calculations required in back-propagation were hard coded into each layer, making larger more complicated layers difficult to implement.
        Today, the project utilizes and auto-differentiation calculator I also wrote myself.  The calculator tracks matrix calculations via a wrapper class called MatrixNode and constructs the sequence of matrix operations required to calculate the gradient from the output to each input.  It was quite task to implement but has been a godsend!
