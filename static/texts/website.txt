This website was my first experience with "modern" web development.  I did develop some basic webpages before, but they were so basic that they might as well have been from 1992.  I kid you not, my print server web portal worked on Internet Explorer 5 running in Windows 3.1 on an AST 386 without any modifications.

<#ff0000>Inspiration<>
The idea of a terminal based webpage was actually one that my student organization CIF proposed in the past.  Yet due to time constraints and maintenance, it wasn't pursued.  In the summer of 2026, I finally acquired a second computer that could host a website, an idea I had been entertaining for a while.  The computer is far from perfect as it was meant for Windows XP and has a whopping 2GB of functional RAM.  It serves its purpose fine though.

<#ff0000>Development<>
Contrary to my friend's suggestion, I entered this project without a framework.  The entire thing is a conglomeration of HTML, CSS, Javascript, and Python; all written by hand by me.  The project utilizes Flask, a Python library for controlling and rendering HTML using Jinja.  Flask is a library I have used in the past.  While the Python portion of the project is not doing terribly much at the moment, the Python availability provides some flexibility in case there are future features I wouldn't be comfortable doing in Javascript.

Javascript manages all the animations and handles the "terminal."  Any and all commands are parsed and processed in a single Javascript file about 200 lines long.

<#ff0000>Design<>
The primary design goal was to make everything as modular as possible.  As such, the project makes liberal use Jinja templates.  To add a new webpage, copy the html template, change the buttons as desired, add the page to file architecture in the javascript file, and specify the contents in Flask.  The webpage contents, including text colors, can even be read from a txt document.
