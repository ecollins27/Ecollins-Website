DESCRIPTION
        CRender is a ray tracing renderer written from scratch in C++. Accessible both as a C++ library and as a command line interface, CRender fully supports the .obj file format and any number of transparent and reflective materials.
        Like many of my other projects, it started out with the goal of learning how graphics rendering worked.  However, it quickly became my favorite project.  There is something so inherently satisfying about creating a project whose output becomes more and more realistic over time.
        The project is still ongoing and there is a lot to be done.  Stay tuned!
