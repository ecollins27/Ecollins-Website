<#ffff00>Status Page<>

DESCRIPTION
        The status page is a custom flask application written for the Computer Interest Floor, designed to monitor any number of servers and their tasks.
        The page is capable of tracking CPU, memory, and disk usage as well as individual systemd service statuses, website status, and user NFS share disk space.

INSPIRATION
        During the fall semester of my junior year, CIF began decommissioning and modernizing much of its network infrastructure.
        It became immediately apparent that the organization required a centralized location for viewing and summarizing network infrastructure.

DESIGN
    The status page consists of two parts - a central server hosting the website and an agent running on the client machines.
    The agent sends small packets via the Python requests library.  These packets contain information on cpu, memory, and disk usage; operating system, the status of system services, etc.
    If a client is hosting an nfs share, the project is also capable of receiving and displaying breakdowns of NFS share disk usage.  These packets are all sent to a central server
    running the bulk of the project.  Here, the packets are parsed and displayed, determining if each server is active, inactive, or active without an agent.
