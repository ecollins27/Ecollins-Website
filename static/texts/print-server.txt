DESCRIPTION
        The print-server is a custom fork of Koushikphy's online web printer (code linked in the Github README) designed for the Computer Interest Floor.
        The project interacts with an external IdM server using the python_freeipa library to authenticate users and remotely send prints via the cups library.

INSPIRATION
        Developing a renderer has been a long standing goal of mine, dating back to high school.

DEVELOPMENT
        This project marked my first introduction to Flask and web development in general.  As such this project provided a good lesson in how websites are structured and hosted
        as well as how one can host their own website, a skill I have obviously utilized.
