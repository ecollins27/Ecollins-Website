DESCRIPTION
        CRender is a ray tracing renderer written from scratch in C++. Accessible both as a C++ library and as a command line interface,
        CRender fully supports the .obj file format and any number of transparent and reflective materials.

INSPIRATION
        Developing a renderer has been a long standing goal of mine, dating back to high school.

DEVELOPMENT
        As with many of my projects, the goal of CRender

Javascript manages all the animations and handles the "terminal."  Any and all commands are parsed and processed in a single Javascript file about 200 lines long.

DESIGN
    The primary design goal was to make everything as modular as possible.  In fact, the design is so modular that every single page renders the same index.html.  Custom elements like images and buttons are specified as plain-text in txt files which are parsed and passed to an html file via a python script.  Javascript then adds the elements in real time as it animates.  The result is essentially a custom text based framework.
